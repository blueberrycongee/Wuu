# 记忆

Wuu 的记忆分两层：**用户笔记本**保存关于你的长期偏好和反馈；**工作区记忆**由 Agent
在工作区内部维护，保存该工作区跨会话仍有价值的事实和经验。两者都只是普通 Markdown
文件，不是独立的数据存储。

## 用户笔记本

用户笔记本保存跨会话仍有价值的个人偏好、反馈、参考信息和经验。它与某次会话历史不同，
也不应成为项目事实或临时任务日志的副本。

### 查看记忆

打开**设置 → 记忆**，或者在输入框中使用 `/memory`。面板提供：

- 根据真实笔记本生成的概览；
- 刷新概览；
- 查看 `MEMORY.md` 索引和记忆文件原文；
- 用对话方式要求添加、修正或删除记忆，并查看实际变更文件。

概览由当前模型生成，并缓存约 12 小时；需要立即反映原文变化时使用刷新。原文视图
才是审计记忆内容的直接依据。

### 适合保存什么

- 长期沟通偏好；
- 用户明确给出的工作反馈；
- 跨项目仍成立的参考入口；
- 以后遇到类似问题仍有用的经验。

不要保存密钥、原始对话、短期任务进度、提交 SHA、一次性日志，或可以直接从当前仓库
重新获得的事实。

### 数据和模型调用

用户记忆默认位于 `~/.wuu` 下的记忆目录；设置 `WUU_HOME` 会整体移动 wuu 的用户
状态。生成概览和通过对话修改记忆会调用当前模型服务，原文读取不需要模型。

记忆可能作为相关上下文发送给模型。处理敏感内容前，请同时检查记忆原文、模型服务的
数据政策和[安全模型](../reference/security-model.md)。

## 工作区记忆

每个工作区有自己的 `project_memory`：Agent 在会话中通过 `session_memory` 工具维护，
用于保存该工作区跨会话仍有价值的稳定事实。它位于工作区状态目录下的 `memory/MEMORY.md`，
与用户笔记本相互独立。

适合写入工作区记忆的内容：

- 架构决策和稳定约定；
- 长期有效的工作流经验；
- 跨会话需要继续使用的项目背景。

`session_memory` 工具还管理会话级文件：`summary`（当前任务的紧凑可恢复状态）、
`checkpoint`（旧版兼容入口）、`notes`（会话草稿）。会话级内容属于单个活跃会话，
不应依赖它们在之后的会话中继续存在。

## 后台记忆整合（Dream）

Dream 会在后台定期检查已完成会话，把值得保留的稳定事实整合进工作区记忆。它默认关闭，
可在**设置 → 记忆**中启用并调整运行间隔；也可以配置专用模型，避免与当前对话争用。
触发条件、配置方式和限制见[后台记忆整合（Dream）](dream.md)。

## 与项目指令的区别

- `AGENTS.md`、`CLAUDE.md` 等项目指令持续影响工作区中的每个任务，适合随仓库共享；
- 用户笔记本保存用户的跨项目长期信息；
- 工作区记忆保存单个工作区的持久事实。

## 记忆的信任边界

记忆内容会进入 Agent 上下文，可能影响它选择工具和处理文件。写入记忆的内容应来自
你自己确认的事实，而不是未经核验的第三方文本；发现记忆被污染时，在记忆面板中删除
对应条目。
